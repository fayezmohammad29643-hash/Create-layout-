# Edition overrides

These files contain only project-specific edition corrections that cannot be represented by the current generic counting-system map.

- `warsh-6213.json`: the project's 6213-ayah Warsh edition. Its al-Nahl numbering differs from the current 6214-ayah Warsh reference, so this override merges Kufan 16:123+124 into project Warsh 16:123 and shifts 124–127 to Kufan 125–128.

Douri 6217 does **not** use a hand-written override: its exact edition correspondence is generated from `quran-text/data/ayah-map.json`.
